# Excel関数プラグイン（kintone プラグイン）

kintone標準の計算フィールドでは使えない Excel 風の関数（AVERAGE・MAX・MIN・COUNT・STDEV・ROUND・IF など）を、レコードの保存時に計算して数値フィールドへ書き込むプラグインです。

Sattonet Service（Satonyan）が無料で配布する公開プラグインの第1弾です。

- バージョン： 1.0.0
- 形式： kintone プラグイン（manifest_version: 1 / type: APP）
- 外部ライブラリ依存： なし（素の JavaScript のみ）

## できること

- 設定画面で「結果を入れるフィールド」と「式」のルールを複数登録できます。
- レコードの新規作成・編集の保存時（submit）に全ルールを計算し、結果フィールドへ値をセットします。
  - 計算結果は値としてレコードに残るので、一覧・集計・検索でもそのまま使えます。
  - 計算エラー時は保存を止めて、理由を表示します。
- 作成・編集画面を開いたときにも初期計算を行います（表示時の計算エラーは無視し、保存時に判定します）。
- サブテーブル（テーブル）の列を集計できます。検査記録の測定値列から平均・標準偏差・最大・最小などを出す用途に使えます。

## インストール

1. `dist/kintone-excel-functions-plugin-1.0.0.zip` をダウンロードします。
2. kintone のシステム管理 → プラグイン → 「読み込む」から zip をアップロードします。
3. 対象アプリの設定 → プラグイン → 「プラグインを追加」から本プラグインを追加します。
4. プラグインの設定（歯車アイコン）で計算ルールを登録し、保存します。
5. アプリ設定画面で「アプリを更新」します。

## 設定手順

設定画面では、ルールを1行ずつ登録します。

| 項目 | 内容 |
|---|---|
| 結果を入れるフィールドコード | 計算結果を書き込むフィールドのフィールドコード。数値フィールドを想定しています |
| 式 | Excel 風の式（書き方は次節） |

- 「＋ ルールを追加」で行を増やせます。各行の「削除」で行を消せます。
- 保存時に全ルールの式を構文チェックします。エラーがある場合は保存せず、理由を表示します。
- 完全に空の行は無視されます。

## 式の書き方

### フィールドの参照

| 書き方 | 意味 |
|---|---|
| `[フィールドコード]` | 通常フィールドの値 |
| `[テーブルコード.列コード]` | サブテーブルの列。全行の値の配列として解決され、集計関数の中で使います |

例：

- `[単価] * [数量]`
- `AVERAGE([明細.単価])`
- `IF([金額] >= 10000, [金額] * 0.1, 0)`
- `IF([状態] = "完了", 1, 0)`（文字列はダブルクォートで囲みます）

### 演算子

- 四則演算： `+` `-` `*` `/`、剰余 `%`、べき乗 `^`、括弧 `( )`、単項マイナス `-`
- 比較： `=` `<>` `>` `<` `>=` `<=`（主に IF の条件で使います。比較結果は真=1 / 偽=0 としても使えます）
- 優先順位は通常の計算と同じで、べき乗は右結合です（`2 ^ 3 ^ 2 = 512`）。

### 関数一覧

関数名は大文字・小文字を区別しません。

| 関数 | 説明 |
|---|---|
| `SUM(値, ...)` | 合計。引数はスカラーまたはテーブル列。複数引数可 |
| `AVERAGE(値, ...)` | 平均。空・非数値は無視します |
| `MAX(値, ...)` / `MIN(値, ...)` | 最大 / 最小 |
| `COUNT(値, ...)` | 数値の個数。空・非数値は数えません |
| `STDEV(値, ...)` | 標本標準偏差（n-1 で割ります）。数値が2つ以上必要です |
| `STDEVP(値, ...)` | 母集団標準偏差（n で割ります） |
| `ROUND(値, 桁数)` | 四捨五入（Excel の ROUND と同じく、0.5 は絶対値方向に切り上げ）。桁数は省略可（省略時は0）。負の桁数も可（例：`ROUND(123.456, -1)` = 120） |
| `IF(条件, 真のとき, 偽のとき)` | 条件分岐。偽のときは省略でき、省略して条件が偽の場合は空になります。選ばれなかった側は評価しません（例：`IF(TRUE, 1, 1/0)` はエラーになりません） |

## 空値・非数値の扱い（v1 の仕様）

- 集計関数（SUM / AVERAGE / MAX / MIN / COUNT / STDEV / STDEVP）では、空と非数値は無視します（Excel の AVERAGE などに倣っています）。
- ただし、対象となる数値が1つも無い場合、AVERAGE / MAX / MIN / STDEV / STDEVP はエラーとして保存を止めます。SUM は 0、COUNT は 0 を返します。
- 四則演算に空のフィールドが含まれる場合、結果は「空」になり、結果フィールドは空になります（0 にはなりません）。
- 空のフィールドとの比較は、`<>` のみ真、それ以外は偽になります。
- テーブル列を集計関数以外（四則演算や比較）で直接使うことはできません。エラーになります。
- 0 で割る（剰余含む）とエラーになり、保存が止まります。

## 制限事項

- 結果を書き込めるのは、式で参照していないフィールドです（結果フィールド自体を式から参照すると、表示時の初期計算と保存時で値が変わる場合があります）。
- 対応イベントは PC 版のレコード作成・編集のみです。モバイル版、レコード一括編集、CSV 読み込み、REST API 経由の登録・更新では計算されません。
- 式の構文チェックは設定の保存時に行います。フィールドコードの実在チェックは行わないため、存在しないフィールドコードを式に書いた場合は、レコード保存時にエラーになります。
- 文字列の結果（IF で文字列を返すなど）を数値フィールドへ書き込むと kintone 側でエラーになる場合があります。結果フィールドは数値フィールドを想定しています。
- 日付・時刻の計算には対応していません。

## 開発者向け

- 式エンジンは `src/formula.js` に独立モジュールとして実装しています（トークナイザ＋再帰下降パーサ。`eval` は使っていません）。ブラウザでは `window.ExcelFormula`、Node では `module.exports` として読み込めます。
- 単体テスト： `node tests/formula.test.js`（依存なし、そのまま実行できます）
- パッケージ化： `src/` の中身を zip 化し、`manifest.json` が zip の直下に来るようにしてください。
