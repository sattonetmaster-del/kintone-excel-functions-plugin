Excel関数プラグイン 設定

計算ルールを登録します。レコードの保存時に式を計算し、結果を「結果を入れるフィールド」へ書き込みます。
式の書き方：フィールドは [フィールドコード]、サブテーブルの列は [テーブルコード.列コード] と書きます。
例）AVERAGE([明細.単価])、IF([金額] >= 10000, [金額] * 0.1, 0)
使える関数：SUM / AVERAGE / MAX / MIN / COUNT / STDEV / STDEVP / ROUND / IF

結果を入れるフィールドコード（数値フィールド） 式 削除

※ 保存後はアプリ設定画面で「アプリを更新」してください。
※ 式にエラーがある場合は保存できません。エラーの理由が上に表示されます。
